# 音源设置

“设置 → 音源”选择歌曲播放地址的来源。默认是“网易云”，可随时切回。网易云登录、搜索、发现、每日推荐、个人歌单、喜欢状态、歌词与封面继续使用原来的直连接口；选择第三方播放来源不会迁移或删除账号。

## 洛雪脚本

在音源页选择“导入脚本”：

- 本地文件：通过 iTunes 文件共享将 UTF-8 `.js` 放入应用 Documents，再从应用列表选择。
- 网址：输入 HTTPS 脚本地址，等待导入校验，查看名称、版本、作者与支持的平台，再手动选择启用。

当前曲库使用网易云歌曲 ID，因此脚本必须声明支持 `wy` 和 `musicUrl`。只支持 `kw`、`kg`、`tx`、`mg` 等平台的脚本可以显示其声明信息，但不能用于播放当前曲库；不会把网易云 ID 当作其他平台 ID。第一版没有增加其他平台搜索或跨平台匹配。

采用嵌入式 QuickJS 解释器实现公开 LX 接口，不要求 iOS 7 系统自带的 JavaScript 引擎支持现代语法。提供的具体 API 与限制以发布记录和运行时测试结果为准；这不代表所有第三方脚本均已实测。脚本依赖 Node.js、DOM 或未提供的宿主接口时可能无法运行，页面会显示错误。

脚本上限 1 MiB。运行堆 16 MiB，JS 栈 256 KiB，单次同步执行预算 500 ms，初始化最多 10 秒，播放地址解析最多 40 秒。超时或内存超限会终止对应任务。脚本网络请求不获得应用的网易云账号 Cookie、Keychain 或本地文件访问权限。

## 仓库音源与更新

设置 → 音源 → 仓库音源，可刷新 [pdone/lx-music-source](https://github.com/pdone/lx-music-source) 的目录，选择导入或更新。列表中的名称在导入后显示脚本原名称、版本和作者。导入后回到音源页手动选择；网易云仍为默认来源。脚本的 `/*`、`/**`、`/*!` 信息头均支持。

“同步仓库音源”只检查已从该仓库导入并绑定订阅的源；本地脚本、其他网址脚本与 API 不会被自动覆盖。自动同步默认开启，应用回到前台时距上次成功检查至少 24 小时才再检查，失败至少间隔 15 分钟。应用关闭时不会后台更新。关闭开关可仅保留手动同步；正在处理时轻点同步行或目录页“取消”停止剩余工作。

“下载方式”提供 GitHub 官方接口，以及仓库 README 给出的 `ghproxy.net`、`gh.llkk.cc`、`github.moeyy.xyz`、`ghproxy.cn`、`gh.api.99988866.xyz`、`ghp.ci`、`gh-proxy.org`。默认使用 GitHub；用户选择后保存，脚本下载使用对应加速路径。目录仍从固定 GitHub API 读取并缓存；加速站点的可用性可能变化，错误会显示，可以切换下载方式后重试。不会自动轮换站点。列表的大小和 Git blob SHA 均用于校验下载结果，加速站返回错误内容或旧缓存时不会覆盖本地源。

GitHub 方式按目录中的 immutable blob SHA 下载同仓库内容，避免原始文件域名超时及两个请求之间 `latest.js` 变化。加速方式按仓库公开链接构造固定 `main/<目录>/latest.js` 地址并校验内容；不一致时刷新目录后重试。新版先在临时脚本引擎初始化，旧版可支持网易云而新版不再支持时保留旧版。源码文件先按修订写入，再原子提交索引；失败保留原脚本、来源 ID 和选择。旧版 1.2.0 的脚本文件继续可读，成功更新后转为版本化路径。

进行中的歌曲解析保留原脚本快照，新解析使用更新后的修订；已起播歌曲继续播放。同步期间删除或更改源时跳过对应更新，不重新创建已删除源。仓库移除源时保留本地旧版并显示原因。仓库目录或脚本下载失败时保留已有配置；GitHub 限流会明确提示。

## 自定义 API

添加 API 时填写名称、请求 URL 模板和返回 URL 字段路径。基础 GET 示例：

可以保存 HTTP 或 HTTPS API 配置。“仅允许 HTTPS”开启时，HTTP 请求及返回的 HTTP 播放地址会被拦截，但不会删除已保存配置。关闭开关后重试即可使用 HTTP。

```text
https://example.com/music?id={id}&quality={quality}&source={source}
```

这是格式示例，不是可用音乐服务。占位符：

| 占位符 | 内容 |
|---|---|
| `{id}` | 网易云歌曲 ID，十进制字符串 |
| `{source}` | `wy` |
| `{quality}` | `128k`、`320k` 或 `flac` |
| `{title}` | 歌曲标题 |
| `{artist}` | 歌手 |

URL 参数中的占位符会编码。默认识别 JSON 的 `url`、`data.url`、`data[0].url`，也支持返回纯文本音频 URL。自定义字段路径使用点分形式，例如 `data.0.url`。3xx 的 Location 作为媒体地址；直接返回音频字节而非地址的 API 不适用于这个控制接口。

高级 JSON 配置可包含 `name`、`url`、`method`（GET/POST）、`headers`、`bodyTemplate`、`urlPath`、`formatPath`、`sizePath`、`bitratePath`。示例：

```json
{
  "name": "我的 API",
  "url": "https://example.com/resolve",
  "method": "POST",
  "headers": {"Authorization": "Bearer YOUR_TOKEN"},
  "bodyTemplate": "{\"id\":\"{id}\",\"quality\":\"{quality}\"}",
  "urlPath": "data.url"
}
```

需按服务文档填写，不支持任意 API 自动适配。Token 为用户自行配置，保存在受保护的私有配置文件中；音源索引仅保存元数据和引用。不要分享带真实 Token 的配置。应用不会从网易云账号提取 Token 给自定义 API。只有可信的实际格式、大小、码率齐全时才使用持久缓存；信息不足时使用原有临时播放缓冲。

## 切换、网络与缓存

- 默认网易云，保存/导入新源后不会自动启用。手动选择一项；切换影响下一次取播放地址，当前已起播歌曲继续播放。需要立即换源时使用播放重试。
- 播放失败时状态文字显示原因，点按文字、音质或右上角详情可查看完整原因、失败歌曲和实际使用的音源，并选择“重试播放”或“切换音源”。保留脚本拒绝原因、API 错误代码、HTTP 状态码和网络错误；消息中的链接与常见凭据隐藏。自动重试只使用原来源及配置版本。
- “仅允许 HTTPS”默认开启，适用于脚本/API 控制请求、第三方音频和音频重定向。关闭后允许 HTTP，地址保持音源原值。开关影响后续请求，已开始的歌曲继续播放；请重试以使用新选项。HTTP 为未加密传输。
- 网易云内置播放、仓库和脚本网址下载继续要求 HTTPS。HTTPS 的 TLS 证书与主机名验证保持开启；音频下载始终移除 Cookie/Authorization。
- 第三方响应最多 2 MiB；音频仍走原有磁盘流式加载。不会把整首歌读到脚本控制响应内存中。
- 删除自定义来源会清理其缓存；正在使用的文件等播放释放后再删除。不会删除用户导入的本地音乐。
- 音质选择是请求偏好；实际标识仍由音频格式和解码信息决定。

## 开源许可

洛雪程序仓库标注 Apache-2.0，README 有补充条款；接口文档采用 MIT。本项目独立实现接口兼容，新增引擎及实质引用的文档内容保留适用版权/许可证。QuickJS 的确切发行版本和 SHA-256 见依赖清单，许可证随 IPA 和源码交付。

第三方脚本按各自许可使用；公开下载不等于允许重新分发。软件代码许可与音乐、封面、歌词和服务使用授权分开。本应用不捆绑第三方商业或未知许可音源，也不表示获得洛雪官方认可。

自写导入示例位于 `tests/fixtures/lx-demo.js`。其中音频 URL 是占位地址，需要替换成你有权使用的 HTTPS 文件；该示例不提供真实第三方音源。
