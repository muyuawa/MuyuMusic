# 暮雨音乐 1.1.0 正式版

日期：2026-11-04（America/Los_Angeles）。构建号：7。

## 更新

- 发现页新增“每日推荐”。登录后读取网易云当前推荐歌曲，支持播放全部、加入队列和原有歌曲操作；下拉刷新可重新获取。
- 设置新增“跟随封面配色”，默认关闭以保留已有自定义颜色。开启后从实际封面提取主色，联动背景、页面表面及控件；关闭或选择手动颜色后恢复自定义配色。无封面/纯白封面回退到手动色，过期歌曲的异步结果不会覆盖新歌。
- 图标、启动画面、封面占位与列表加载标记采用用户提供的猫耳少女图片。原图位于 `assets/AppArtwork.png`，可运行 `python3 scripts/draw-assets.py` 重新生成资源。
- 应用内说明精简为登录、导入、缓存清理和开源许可等必要信息。
- 移除持续播放诊断、阶段快照、诊断计数及对应同步开销；首次启动清理旧诊断文件。保留正常错误提示和重试。
- 正式包关闭调试附加权限，保留原有播放缓冲、缓存保护、歌词、图标控制、音源权限和 TLS 校验。

## 系统与安装

最低 **iOS 7.0**，32 位 **ARMv7**。实际验证设备为 iPod4,1 / iOS 7.1.2 (11D257)。其他版本没有完整真机验收；iOS 11 及以上不能运行 32 位应用。安装仍需支持 ad-hoc 签名的越狱环境。

交付：`MuyuMusic-1.1.0-armv7.ipa`、`MuyuMusic-source-1.1.0.zip`、`SHA256SUMS.txt`。

## 验证

- `bash scripts/test.sh` 全部通过：封面主色及深浅背景对比度、布局、日推登录/64 位顺序/元数据/无效数据/错误、原有网络、LRC/曲库 227 项、播放核心和缓存 124 项。
- `PLAYBACK_SANITIZE=1 bash tests/playback.sh` 通过；保留精确 PCM、欠载补缓冲和短尾部行为。
- 使用 SDK 7.1 实际 ARMv7 编译、链接、SHA-1 + SHA-256 签名，Mach-O 最低版本为 7.0；包校验确认无持续诊断入口，`get-task-allow=false`。
- USB 传输、安装、查询均返回 0；设备回读版本 1.1.0 / 构建 7。覆盖升级保留用户数据。
- 用户反馈“可以了”；安装后系统截图确认真实每日推荐列表正常显示，以及不同封面对应蓝色/橙红色主色与背景。真机沙盒检查确认旧 `PlaybackDiagnostics.json` 已不存在。
- 无登录凭据的生产 HTTPS/EAPI 探测实际返回 200 和 30 首。未将该结果作为已登录个性化推荐证据；已登录界面的证据来自用户设备截图。

上述验证不代表所有音频格式、长期后台播放和所有系统版本均已完成验收，参见 [兼容限制](../COMPATIBILITY.md)。开发时的历史截图、日志及诊断记录保留在工作区，不包含在精简源码交付包中。
