# 暮雨音乐 1.2.0

日期：2026-11-06（America/Los_Angeles），构建 8。最低 iOS 7.0 / ARMv7。

## 功能

- 设置 → 音源，提供“网易云”“洛雪脚本”“自定义 API”三种来源。网易云仍默认选中、不可删除，原登录、直连请求、搜索、日推和个人歌单保留。
- 支持从 Documents 或 HTTPS 网址导入 UTF-8 `.js`，显示头部信息、平台及可用状态，手动启用、切换和删除；相同内容去重，同名不同内容不覆盖。
- 当前曲库为网易云，脚本调用 `wy` / `musicUrl`；其他平台脚本显示不可选原因。没有新增跨平台搜索或歌曲 ID 匹配。
- API 提供 URL 模板及返回字段配置，高级 JSON 可配置 POST、请求头、JSON 请求体和实际资源字段；支持 JSON、文本 URL 和绝对/相对 3xx 媒体地址。密钥、URL 查询串与请求体放在受保护的私有配置文件，音源索引仅保留元数据及引用。
- 独立实现 LX 接口兼容，嵌入 QuickJS 2026-06-04；支持 Promise/async、定时器、HTTP/取消、buffer、MD5、随机字节、AES CBC/ECB、raw RSA 和 zlib。
- 自定义连接仍要求 HTTPS 及证书/主机名验证；不会获得应用网易云 Cookie 或 Keychain。来源、配置版本、媒体主机及有效端口隔离缓存，元数据不完整时使用临时缓冲；删除源时保护当前正在读取的缓存文件。
- 导入或选择不会删除本地曲库、歌单、主题与原账号；损坏音源配置恢复至网易云，保存修复结果并显示一次提示。脚本更新提醒只展示文本，用户点击后才打开 HTTPS 地址。播放失败可明确选择重试或切换音源；自动重试验证来源快照，避免自动转发给刚切换的其他源。

## 限制

- 尚未提供用户实际使用的脚本/API，不能保证所有第三方源兼容或其服务可用。自写示例位于 `tests/fixtures/lx-demo.js`，地址为需用户替换的占位值。
- 运行环境不是 Node.js 或浏览器，不提供 DOM、文件系统、进程或共享内存 Atomics。脚本上限 1 MiB、运行堆 16 MiB、同步执行预算 500 ms、初始化 10 秒、解析 40 秒、控制响应 2 MiB、HTTP 并发最多 4。
- JS 栈使用 256 KiB，为 GCD 512 KiB 原生线程栈保留桥接与异常展开空间；递归以受控错误结束。
- 软件许可与脚本、音乐、封面、歌词和服务权限独立；具体说明见 [音源说明](../CUSTOM-SOURCES.md) 与 [依赖清单](../DEPENDENCIES.md)。

USB 传输、安装、安装后查询均返回 0；连接设备为 iPod4,1 / iOS 7.1.2，回读版本为 1.2.0 / 构建 8。使用原 Bundle ID 覆盖升级。用户重新打开后反馈“都正常”，确认音源页默认网易云、原账号和网易云播放正常。实际第三方脚本/API 导入与试听尚未验证，不将安装或构建通过视为这些验收已完成。
