# 暮雨音乐 1.3.0

构建 9。最低 iOS 7.0 / ARMv7；沿用 com.muyu.cloudmusic 升级。

## 功能

- 设置 → 音源增加 pdone 仓库目录、手动同步、默认开启的自动同步与下载方式。目录动态读取 `latest.js`，支持离线缓存和错误结果查看；导入后手动选择播放来源。
- 自动同步在前台每天检查一次，仅更新用户已绑定的源；失败至少间隔 15 分钟。没有应用关闭时的后台任务，也不自动导入所有源或切换当前来源。
- GitHub 官方方式使用同仓库 Git blob API；加速方式提供仓库 README 的 ghproxy.net 及六个备用站点。目录 SHA 和大小校验适用于所有方式，不自动轮换下载站。
- 更新保持 source identifier，内容变化生成新 revision。先写版本化脚本，再原子提交索引，失败保留旧版；原 1.2.0 路径可读。支持相同内容绑定订阅、原版本文本不变的内容更新、删除/更改期间跳过、仓库移除后保留旧源。
- 新版初始化失败或失去旧版的网易云 `wy/musicUrl` 能力时保留旧版。当前解析使用旧快照，下一次使用新修订；网易云登录、直连、默认来源、本地曲库与 API 配置保留。
- 支持真实洛雪脚本使用的 `/*`、`/**`、`/*!` 信息头，并按原始 UTF-8 字节（含 BOM）校验和保存。
