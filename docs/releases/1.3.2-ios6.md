## 构建 19：底部播放栏位置

从播放页进入歌曲菜单、浏览歌手或专辑时，导航栈中的播放页仍使底部导航隐藏。原布局固定使用底部导航的旧坐标，使播放栏下方留下约 49 点空白。本次按当前导航栈的隐藏状态选择屏幕底边或导航上边作为播放栏的下边界，并在页面切换前后请求重新布局。返回播放页时沿用原有隐藏播放栏的生命周期处理。

播放生产代码没有改动。构建 18 的格式识别和后缀兼容逻辑同时用于 iOS 6 与 iOS 7 及以上；只有 iOS 6 禁用原生渐进式起播。新增回归检查在渐进式模式下将 MP3、M4A/ALAC、AAC、WAV、AIFF 和 FLAC 分两块送入真实音源与 spool，确认下载完成前触发起播、格式与后缀正确、后续字节继续写入同一播放文件，并在结束后正确清理。

本轮验证：

- 布局回归先复现旧算法下的贴底断言失败，修复后导航隐藏／恢复及两种屏幕高度检查通过。
- `bash scripts/test.sh` 完整主机回归通过，包括渐进式起播、旧缓存格式、截断、取消、网络、曲库、音源与脚本运行时。
- `bash tests/ios6_compile.sh` 全部源文件 ARMv7 / iOS 6.0 API 检查通过。
- `bash scripts/build.sh` 构建、包架构、最低系统、资源及签名检查通过；IPA 内回读 `1.3.2 / 19`。
- 独立代码审查没有发现需要修正的重要问题。本次未进行真机页面导航、视觉或听音验收，主机渐进式检查不能代替 iOS 7 及以上真机验证。
