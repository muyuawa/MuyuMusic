# 1.3.1 iOS 6 本地测试分支

- 分支：`codex/ios6`，基于原版 `0c01844`，未推送 GitHub。
- 版本：1.3.1 / 构建 15；最低系统 iOS 6.0，架构 ARMv7。
- 安装包：`dist/MuyuMusic-1.3.1-ios6-armv7.ipa`。
- 源码：`dist/MuyuMusic-source-1.3.1-ios6.zip`。

## 兼容变化

保留 1.3.1 的自定义音源、仓库订阅、加速下载、HTTPS 策略和错误详情。URL/Base64 编码改用旧系统可用接口；主题、导航栏、按钮、文字绘制和布局避免无保护的 iOS 7 API。

二维码改用 Nayuki v1.8.0 C 库本地生成（MIT），保留原网易云登录流程。iOS 6 上 MP3/AAC/M4A 等系统音频先完整下载后播放；FLAC 保留增量解码。iOS 7 上原渐进式加载继续使用，有运行时可用性保护。

依赖目标标记防止复用原版 iOS 7 的 ARMv7 归档。包校验检查应用与所有静态依赖的最低系统、ARMv7 架构、SHA-1 主签名、系统动态库、entitlements、CA 和许可证。文件名带 `ios6`，保留已有原版测试包。

## 验证范围

已通过完整 `scripts/test.sh` 主机回归，新增 URL/Base64 编码、登录二维码解码回读、原生/FLAC 起播时机、截断/取消和 Theos 依赖预检测试。全部源文件通过 ARMv7 / iOS 6.0 严格 API 可用性编译。libFLAC、libcurl、Mbed TLS 和 QuickJS 已重新构建为最低 iOS 6.0，IPA 通过架构、部署目标、静态库、签名和资源检查。现代 clang 的系统版本检查引用以可缺省的 weak import 链接，`nm` 和 `dyld_info` 均确认该属性。

用户随后要求安装：已通过 USB 覆盖安装到 iPod4,1 / **iOS 7.1.2**，安装返回 0，应用列表回读 **1.3.1 / 构建 14**。这仅证明该设备接受安装，没有执行 iOS 6 真机安装、扫码授权、试听或后台验收；仍需用户测试。设备安装步骤和检查项目见 [INSTALL.md](../INSTALL.md)。不把原 iOS 7 真机记录算作本分支验收。

## 构建 14：统一扁平界面

按用户测试反馈，搜索框外层在浅色模式下固定白色，搜索输入框改为无渐变的浅灰底；分类和播放页分段控件为所有选中/按住/禁用状态及分隔线指定图片，消除默认蓝色高光边缘。底部导航显式设置各状态文字颜色和原色图标，避免白底上选中文字消失。

列表、分组说明、开关、返回按钮与所有应用内消息/输入/确认/选择弹窗统一为自绘或纯色扁平视图。弹窗支持长文/选项滚动及键盘避让，关闭并恢复主窗口后再执行回调；切到后台时输入弹窗取消并清除输入。下拉刷新用文字提示代替默认拉伸控件。

队列“编辑”后点歌曲或右侧按钮，可上移、下移、指定位置或移除。左滑队列打开同一菜单；左滑本地歌单或歌单内歌曲打开扁平删除/移除确认。底层队列与曲库操作保持原接口。新建歌单使用“新建”文字按钮。

代码编译、回归与包检查结果以构建日志为准；本次重绘后的真机截图和交互仍需用户验收。


## 构建 15：歌曲菜单、网易云歌单与播放托盘

播放页的队列和三个点组合为一个固定宽度导航项，标题放在限宽容器内；特别覆盖“打开歌单页面后，点底部正在播放歌曲”的入口，长歌单名或歌词标题不会挤占队列空间。返回过渡中暂时隐藏离开的自绘返回文字，完成后恢复，避免与上一级导航按钮重叠。

三个点复用选歌页的歌曲操作菜单，包括队列、本地收藏、本地歌单、歌曲信息、浏览歌手/专辑、网易云喜欢，以及“加入网易云歌单”。目标列表完整分页后仅列出当前账号创建的歌单；本地文件不显示网易云操作。主页推荐歌单、搜索歌单和网易云歌单列表的右侧菜单新增“收藏到网易云”。未登录时提供扫码登录入口，服务拒绝、重复添加及网络失败均显示返回原因。

底部播放托盘增加主题色的两点高进度线和上一曲、下一曲按钮，左右滑动可切歌；播放页左右滑动仅切换封面和歌词，不切歌，进度条和按钮区域保留原交互。歌词仍可纵向滚动。托盘整体隐藏或恢复，避免新增按钮残留在全屏播放页。

设置的“关于”分组增加“使用协议”；音源页面增加可滚动阅读的“第三方音源免责声明”，导入和仓库列表同时显示简要说明。文本说明版权与服务条款、外部请求、安全及可用性，不设置额外的启动确认步骤。

新增歌单接口回归覆盖登录限制、64 位编号、分页后的创建者筛选、目标歌单参数和网络/服务错误；全部来源仍按 ARMv7 / iOS 6.0 构建。最终安装和检查结果以构建 15 日志及设备回读为准，界面和真实账号操作仍需用户复测。


构建 15 验证结果：完整 `scripts/test.sh` 回归、全部源文件 ARMv7 / iOS 6.0 API 检查，以及 IPA 架构、资源和签名检查通过。USB 安装首次遇到会话发送错误；重试后安装返回 0，iPod4,1 / iOS 7.1.2 应用列表回读为 `1.3.1 / 15`。未推送 GitHub；真实账号歌单操作、手势和视觉结果仍需用户验收。
