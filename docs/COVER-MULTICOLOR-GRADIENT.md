# 二维自适应多色融合遮罩

版本：1.3.13 / 32。分支：codex/cover-multicolor-gradient。
基线：179071b，保存 1.3.11 / 30 渐变版。局部模糊实验不用于本分支。

MCCoverAppearance 使用当前封面经方向处理与 Aspect Fill 裁切后的 48×48 RGBA。底部实际遮罩区域划分为 5×3 个节点，大封面（宽度至少 300pt）为 7×3。节点保存代表颜色、亮度、饱和度、变化程度、可信度和保护强度。中值与 10%／90% 截尾均值降低小 Logo 和异常像素影响；浅色中性底色另抑制孤立深色文字污染，不丢弃中性背景。

节点在 OKLab 空间做有限邻域平滑，按统一深／浅文字方向协调明度，越出 sRGB 时收缩色度。二维 Smoothstep 插值使用凸权重，保持相邻颜色连续且不发生过冲，保留左右与上下不同色相。遮罩颜色不由单个平均色或用户 Primary 色代替。

透明度独立计算：上端为零，在实际首行字形区域前平滑达到必要强度，随后维持保护；空间强度由局部图案变化及最终合成背景的对比度决定。对歌名、歌手和收藏的采样覆盖区搜索约 4.65:1，给低分辨率重建与量化留余量；最终不足 4.5:1 时保留轻微描边。该指标针对分析样本，不代表原生字形实测。音质 Chip 保留原圆角、参数格式与 12% 主题色混合策略，独立计算标签颜色。

原有封面大小、位置、圆角、单行标题宽度、歌手／音质／收藏位置、封面歌词切换、进度与五按钮保持。只调整透明遮罩范围，220pt 封面从约 62% 高度开始，覆盖约 38%；按信息高度适配更大封面。没有胶囊信息容器、模糊背景或智能避让。

后台串行 NSOperation 完成分析和 128×96 遮罩 RGBA 重建，主线程安装 UIImage 并保留 0.22 秒显隐动画。参数／图像缓存最多 16 组、成本约 2MiB，分析副本最多 16 组、256KiB；内存警告清空可重建缓存。切歌和必要参数变化取消旧操作，结果安装同时校验封面身份、参数键和代次。进度、歌词、音量、暂停不重算；透明图像的主题背景变化参与键。

本次只打包和安装，未追加执行主机测试或真机视觉检查。现有回归用例已调整为二维场，并加入横向／纵向色彩差异、连续性和预乘 alpha 边缘用例，尚未执行。实际白底 Logo、深蓝风景、彩色插画、混合明暗封面与性能由用户验证。
