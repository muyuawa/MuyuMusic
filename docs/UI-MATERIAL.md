# Material 风格 UI 重构

沿用 Objective-C、UIKit 和现有网易云／本地曲库／播放服务。MCTheme 作为统一 ThemeManager，提供主题色、容器色、前景色、字体与圆角；这是兼容旧 UIKit 的 Material 风格实现，不依赖 Android 组件或新 iOS API。

发现页使用一张每日推荐主卡、四个紧凑入口、横向推荐歌单／最近播放与 60pt 歌曲行。登录后读取现有每日推荐；未登录时展示登录入口和本地最近播放，不编造推荐歌曲。所有入口复用现有列表、歌单菜单和播放器。

当前 1.3.11 / 30 源码的播放页以沉浸式圆角封面卡片为中心，底部根据实际封面局部颜色与文字对比度生成平滑、自适应强度的渐变，并在第一行文字前达到必要保护强度。歌名固定单行，歌手、音质 Chip 与收藏保持封面内紧凑布局，点按仍可一起淡出／淡入；歌词模式替换整个卡片。封面、正文、进度条和五按钮的坐标沿用 1.3.9，内容宽度在平板上设上限。收藏与音质触摸区域至少 44pt，歌名保持独立点击查看完整信息。

使用带少量主题色的背景、surface、surfaceContainer、surfaceContainerHigh、primaryContainer 与对应前景；浅色和深色分别计算可读颜色。圆角按组件层级使用，避免逐行大白卡、模糊与阴影。所有图标使用 Core Graphics 路径绘制。

实施顺序：统一颜色和组件 → 发现页 → 播放页与迷你播放器 → 其余页面样式和 iPad 支持。验证仅限布局、主题对比度、iOS 6 API 检查与必要打包；不重复业务回归。
