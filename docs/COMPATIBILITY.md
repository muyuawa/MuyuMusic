# 已知兼容性限制

当前为 **1.3.1 / 构建 16，iOS 6 兼容分支 `codex/ios6`**，最低 iOS 6.0，32 位 ARMv7。iOS 11 及以上无法运行 32 位应用。仅本地交付测试，未推送 GitHub；本次没有 iOS 6 真机安装或听音证据。原 iOS 7.1.2 的设备记录仅属于之前的版本，不代表本分支已在真机通过。

- 主题、文字绘制、按钮和状态栏改用 iOS 6 可用 API，iOS 7 的布局设置有运行时保护。
- 登录二维码由本地 Nayuki C 库生成，不依赖 `CIQRCodeGenerator`。
- 自定义源和仓库下载使用 iOS 6 可用的 URL/Base64 编码接口，保留凭据隔离及 TLS 校验。
- iOS 6 在线 MP3/AAC/M4A/WAV/AIFF 先完整下载再交给系统解码，避免调用 iOS 7 的资源加载数据接口；FLAC 保留原有流式解码。iOS 7 继续使用原有渐进式路径。
- 所有 ARMv7 静态依赖按 iOS 6.0 重新构建，最终包校验检查静态库成员与主程序最低版本。

## 格式与流式行为

- 本地 MP3、AAC、ALAC、WAV、AIFF 使用系统 AVFoundation，支持范围最终受该非官方固件的原生解码器影响。
- FLAC 支持原生 `.flac` 的单/双声道、4–32 bit PCM 解码；Ogg FLAC 和多声道 FLAC 不支持，返回明确错误。源格式标识不保证 iPod 的实际模拟输出达到该采样率或位深，硬件可能转换。
- iOS 7 上已知总长度和已识别格式的在线 MP3/AAC/M4A 通过渐进式资源加载；iOS 6 上这些格式等待完整下载。FLAC 通过增量 libFLAC 解码。未知长度/未知容器需要先完成下载；M4A 的索引在文件尾部时可能等待尾部元数据。
- 向尚未下载的区域定位会等待顺序下载抵达，未实现远程并行 HTTP Range 加速。这会影响很大的无损文件向后跳转速度。
- 单曲在线临时磁盘文件最大 1 GiB，避免无限下载耗尽旧设备存储；内存只保留小块数据。应用退出后不提供下载曲库功能。
- 完整在线歌曲另有持久 LRU 缓存（默认 256 MiB，可关闭或设置至 1 GiB）。当前临时流式文件不计入保存缓存上限；活动缓存被清理或超限时会延迟删除。缓存重播仍需联网确认权限，不是离线下载曲库。系统可能自行清除 Caches。
- 非法/损坏文件会在扫描或实际解码时失败。扫描器不完整解码每个文件来证明所有音频帧都正确；具体元数据/封面限制见 [LIBRARY.md](LIBRARY.md)。

## 服务、TLS 与系统

网易云接口属于非官方兼容协议，平台更改、风控、地区和账号权限可能导致请求失败。默认网易云直连仍只允许原有网易云媒体域名。用户明确选择的脚本/API 可返回其他 HTTPS 媒体主机，重定向仍须 HTTPS、证书与主机名验证通过；不会自动回退到 HTTP 或把网易云账号凭据发给自定义来源。

1.2.0 / 构建 8 新增自定义音源。当前歌曲目录仍来自网易云，洛雪脚本第一版调用 `wy` / `musicUrl`，不提供其他平台搜索或 ID 匹配；未实测的第三方脚本不能视为已兼容。API 按配置的 URL 模板及响应字段解析，无法自动兼容任意接口。现代 JS 由嵌入 QuickJS 解释器执行，不提供 Node.js、DOM、文件系统或进程 API，并设置了内存、执行时间、响应与并发上限。详见 [音源说明](CUSTOM-SOURCES.md) 与 [1.2.0 验证记录](releases/1.2.0.md)。

TLS 使用独立 libcurl/Mbed TLS 和 CA bundle，不依赖旧系统根证书；设备日期仍需正确。已验证同版本后端在主机上的正向 HTTPS 和无效证书拒绝；旧版本有实际在线播放反馈，但真机网络切换和异常证书检查仍待执行。

FLAC 输出缓冲在 44.1 kHz 双声道时约 1.5 秒，高采样率下受每块 128 KiB 上限影响会更短。缓冲可以吸收短时解码/调度波动，不能弥补持续低于播放所需速度的下载或解码。

后台音频、锁屏信息、耳机遥控、音频中断恢复均有实现；但固件移植可能存在音频服务或驱动差异。长时间内存占用、实际流畅度和耗电尚未测量，没有声称达到任何实测帧率或内存数字。

签名包含旧版 iOS 可用的主 SHA-1 CodeDirectory，以及现代 macOS 要求的附加 SHA-256；这是 ad-hoc 签名，仍需支持该固件的越狱安装环境。Keychain entitlement 使用应用自己的 `com.muyu.cloudmusic` 组，实际 securityd 行为待真机核验。

Theos 配置已提供，但未在 Theos 环境执行；交付 IPA 来自本仓库可执行的 clang/ld-classic 构建流程。Apple Silicon、其他系统版本与设备均未声称验证。
