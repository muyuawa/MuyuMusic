# iOS 6 分支安装与测试

本地测试包：`dist/MuyuMusic-1.3.1-ios6-armv7.ipa`，版本 1.3.1 / 构建 13，最低 iOS 6.0、ARMv7。本分支尚未发布到 GitHub，原版 Releases 不包含此测试包。

IPA 使用 ad-hoc 签名（主 SHA-1 和附加 SHA-256）。设备须已越狱，并具备适用于当前固件的 unsigned/ad-hoc IPA 安装支持。本次按用户要求，已覆盖安装到连接的 iPod4,1 / iOS 7.1.2，并回读确认构建 13；没有安装或更改越狱工具。iOS 6 真机验收仍待进行。

## 安装

1. 确认设备为 iOS 6.0+ 的 ARMv7 设备，系统日期正确，存储空间充足。
2. 先备份应用的 Documents、歌单和设置。沿用设备现有、适用于该系统版本的 IPA 安装器。
3. 把本地 `MuyuMusic-1.3.1-ios6-armv7.ipa` 传入设备并安装。若设备已有可用的 `appinst`，可执行：

   ```sh
   appinst /var/mobile/Media/MuyuMusic-1.3.1-ios6-armv7.ipa
   ```

4. 应用标识仍为 `com.muyu.cloudmusic`，会覆盖同标识旧版本；本地曲库和原音源配置按原目录读取。需要回退时使用此前保留的原版 IPA，数据恢复以备份为准。

## 首轮真机测试

- 冷启动、发现/搜索/音乐库、设置、深浅主题，以及进入/退出播放页。
- 账号页生成二维码，用另一部手机的网易云扫码确认，重开应用检查登录状态。
- 本地 MP3/M4A/FLAC；在线 MP3/AAC 等待下载完整后播放；FLAC 缓冲后起播。
- 洛雪脚本导入、自定义 API、仓库刷新/导入/同步和加速下载。
- 暂停/继续、定位、切歌、耳机与后台音频；网络错误详情和 HTTPS 开关。

iOS 6 上 MP3/AAC/M4A 的首次起播等待时间取决于整首下载速度。FLAC 的流式路径保持原实现；两者仍受网络、设备性能及第三方服务状态影响。主机测试及构建证据见 [分支记录](releases/1.3.1-ios6.md)。
