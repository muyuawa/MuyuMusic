# 安装与使用

本 IPA 面向已越狱的 iPod touch 4、Legacy iOS Kit 非官方 iOS 7.1.2。它使用 ad-hoc 签名，没有 Apple App Store / 企业 / 开发者分发证书；需要设备已有适用于该固件的 unsigned/ad-hoc IPA 安装支持。已通过 USB 识别目标设备并读取旧版本实际 FLAC 播放缓存；本次更新的安装与听音证据见 [发布记录](releases/1.3.1.md)。

## 安装 IPA

1. 确认设备处于已越狱状态，系统版本为 7.1.2，系统日期正确，并留出音乐缓存空间。
2. 使用支持该固件的 [AppSync Unified 官方发行版](https://github.com/akemin-dayo/AppSync)，以及设备现有的 IPA 安装器。官方项目明确包含 iOS 7 支持；这不等于本次验证了非官方 iPod4,1 固件的安装组合。不要安装现代 arm64-only 版本的工具。
3. 从 [Releases](https://github.com/muyuawa/MuyuMusic/releases/latest) 下载 `MuyuMusic-1.3.1-armv7.ipa`，传入设备，例如 `/var/mobile/Media/`，用安装器打开并安装。若设备已经有 `appinst`，可在设备终端/SSH 中执行：

   ```sh
   appinst /var/mobile/Media/MuyuMusic-1.3.1-armv7.ipa
   ```

4. SpringBoard 出现“暮雨音乐”后打开。若安装器报签名或完整性错误，检查其与 AppSync 的支持情况；本包不能直接作为普通未越狱设备的签名应用安装。

正常通过安装器安装会创建应用沙盒，iTunes 文件共享才能识别。不建议只把 `.app` 复制到 `/Applications` 作为本包的标准安装方法。

## 导入和离线播放

电脑上的 iTunes → 设备 → 文件共享 → 暮雨音乐，将音乐文件和同名歌词文件拖入 Documents。可使用子目录。AAC/ALAC 通常使用 `.m4a`；原始 AAC `.aac`、`.mp3`、`.flac`、`.wav`、`.aif/.aiff` 也可扫描。

返回应用 → 音乐库 → 本地歌曲。应用激活时自动扫描；右上“扫描”显示导入数量与文件错误。搜索、歌单、本地收藏、最近播放和本地歌词均无需联网。新建歌单后，使用歌曲右侧详情按钮添加歌曲；左滑可移除歌单项或删除本地歌单。

## 网易云和音质

在账号页面生成二维码，用另一部手机上的网易云音乐扫码并确认。二维码过期后重新生成。会话保存在本机 Keychain，可在账号页面退出删除。

搜索可切换歌曲/歌手/专辑/歌单，结果来自真实接口。个人歌单与每日推荐需要登录；喜欢的音乐从“我的网易云歌单”进入。网易云直连返回拒绝、试听或版权限制时显示错误。设置 → 音源可手动选择自定义脚本/API，也可随时切回网易云；原账号、日推、歌单与搜索接口保留。具体配置见 [音源说明](CUSTOM-SOURCES.md)。

歌单中个别歌曲暂无详情时，页面显示已取回的真实歌曲以及加载/总数/缺失数量，可点击重试。已在歌单响应中返回的真实详情会保留；不会生成虚构歌曲或因一首详情缺失而阻止整个歌单打开。网络请求失败和无效数据仍会明确报错。

设置中的标准/高品质/无损优先只影响请求。正在播放页显示实际格式或解码信息；不同歌和账号可得到不同音质。网络中断或链接失效会进行有限恢复，也可点播放错误重试。

## 主题与每日推荐

发现 → 每日推荐，获取网易云当前推荐歌曲，可播放全部或下拉刷新。未登录时页面提供登录入口。

设置 → 跟随封面配色，按正在播放的封面改变主色和背景。关闭后恢复自定义颜色；选择主题色或自定义 HEX 会切回手动配色。

## 预缓存与歌曲缓存

在线 FLAC 会先在磁盘积累约 5 秒音频再起播，遇到数据不足时重新补缓冲。网速较慢时会多等一会儿；已完整下载或本地文件直接播放。

音乐库 → 主题与设置 → 播放与缓存，可查看歌曲缓存占用、选择上限并清理。默认 256 MB，支持关闭、64/128/256/512 MB 和 1 GB。完整下载的歌曲自动缓存，空间不足时优先移除最久未使用的歌曲。

清理会保留正在使用的缓存文件，等播放引擎释放后再移除，界面会提示待清理。清理前开始的下载即使随后完成，也不会重新写入缓存；之后新播放的歌曲仍可缓存。歌曲缓存上限不包含正在下载歌曲的临时文件；关闭缓存后仍需要当前歌曲的临时磁盘空间。

重复播放缓存歌曲仍会向网易云确认当前账号权限，需要联网。需要完全离线播放时，请通过文件共享导入本地音乐。

## 常见问题

- 打不开：保存安装器错误、应用崩溃日志、实际型号/系统版本；先确认越狱和签名支持，没有通过真机验证的结论可代替这些信息。
- HTTP 播放地址被拦截：设置 → 音源 → “仅允许 HTTPS”默认开启。需要使用可信的 HTTP 第三方音源时关闭，再点“重试播放”。网易云及脚本下载仍使用 HTTPS。
- HTTPS/证书错误：校正设备日期，检查网络及 CA bundle。HTTPS 连接始终验证证书和主机名。
- 播放失败：点播放页的错误文字或右上角详情，查看歌曲、音源和具体原因，可重试或切换来源。
- 没有音乐：确认文件已放入应用 Documents，点击扫描并查看错误。损坏/不支持的文件不会冒充导入成功。
- 锁屏后停止或音频初始化失败：记录当前文件格式、错误与固件信息；需要在该非官方固件上实际核验 AudioQueue/AVAudioSession。
- 封面缓存：设置中可清理；本地音频文件不会因此删除。

升级前可用文件共享备份 Documents 中的音乐；应用数据库位于沙盒 Library，不在 Documents。卸载应用会删除本地库、音乐与歌单，先备份所需数据。
